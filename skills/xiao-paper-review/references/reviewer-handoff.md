# Optional independent reviewer handoff

Use only when the user authorizes an independent-agent workflow. This skill does not itself authorize delegation or external publication of a draft.

Give the agent the actual draft and an appropriately scoped task:

> Read the supplied manuscript locally and use xiao-paper-review. Reconstruct its strongest contribution, then give prioritized concerns with exact locations, consequences, and smallest sufficient repairs. Separate validity issues from optional extensions. Do not rewrite files or contact external services. State what you cannot assess. Do not infer private author intentions or mimic a named person's identity.

For independence, do not give the reviewer a desired verdict or hidden fault list. Reconcile disagreements against the source manuscript, not by averaging opinions. Two agents agreeing is not experimental validation.
